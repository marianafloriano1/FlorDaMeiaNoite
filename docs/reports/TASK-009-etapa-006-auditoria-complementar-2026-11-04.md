## Correções de contrato aplicadas ao registro

- O timestamp de agenda é descrito como timestamp de servidor produzido pela RPC com `clock_timestamp()`; não se afirma que a expressão SQL é `now()`.
- A consulta sem sessão retorna HTTP 401 com `authentication_required`; para outro cliente, RLS resulta em HTTP 404 `order_not_found`.
- Same-origin inválida é rejeitada com HTTP 403 antes de sessão/RPC. Customer em endpoint administrativo recebe HTTP 403; para employee em ação restrita a admin, o código é `admin_role_required`.
- A transição operacional enviada é `picked_up`; `resolved`/`cancelled` pode ser o estado agregado final da ordem após resolução de todas as linhas.
- A evidência de T010 distingue violação da constraint da comprovação do rollback transacional. T011–T013 também distinguem estado final de timestamps/resultsets necessários para demonstrar o prazo e a progressão intermediária.
